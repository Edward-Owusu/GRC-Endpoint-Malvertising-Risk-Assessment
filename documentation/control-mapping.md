# Framework & Control Mapping

## NIST CSF 2.0

The project references:

- **PR.AT-01 — Awareness:** Supports workforce awareness and training related to security threats.
- **PR.IR-01 — Network and Environmental Resilience / Protection:** Supports protective measures around endpoint and network environments.

## ISO/IEC 27001:2022

The project references controls related to:

- **A.8.20 — Network Security**
- **A.7.10 — Storage Media / information-handling considerations**

> Framework mappings should always be validated against the organization's adopted control catalog and statement of applicability before being used as formal compliance evidence.

## CIS Controls v8

The project references:

- **Control 14 — Security Awareness and Skills Training**
- **Control 9 — Email and Web Browser Protections**

## Control Strategy

| Control Area | Control Type | Objective |
|---|---|---|
| Browser notification restrictions | Preventive | Reduce exposure to malicious web notifications |
| Least privilege | Preventive | Limit unauthorized software execution |
| Security awareness | Preventive/Detective | Improve user recognition and reporting |
| Periodic audit testing | Detective | Validate control effectiveness |

## Important Note

Framework mappings are provided as a portfolio demonstration. Organizations should confirm the exact control statements, implementation guidance, scope, and applicability against their licensed/current framework materials.
