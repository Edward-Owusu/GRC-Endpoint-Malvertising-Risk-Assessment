# Endpoint Security & Notification Hygiene Policy

**Document Reference:** PL-SEC-004  
**Version:** 1.0  
**Status:** Sanitized Portfolio Case Study

## 1. Purpose

This policy establishes technical restrictions and user expectations for browser-based notifications and endpoint security alerts.

The objective is to reduce exposure to malicious advertisements, deceptive browser notifications, and unauthorized software execution.

## 2. Scope

This policy applies to corporate endpoints, corporate laptops, virtual desktop infrastructure, and workforce members using company assets.

## 3. Policy Requirements

### 3.1 Centralized Security Notifications

Legitimate endpoint security alerts and software updates should be centrally managed through approved enterprise IT and security tooling.

### 3.2 Browser Notification Restrictions

External web domains should not be permitted to create unauthorized browser push notifications on managed corporate endpoints.

Browser notification controls should be centrally enforced where technically appropriate.

### 3.3 Software Installation

Users should not execute or install software obtained through browser pop-ups or untrusted external prompts.

Requests for unapproved software should follow the organization's approved application/software request process.

### 3.4 Reporting

Users should report suspicious browser notifications or suspected malicious activity to the designated IT/security support function.

## 4. Non-Compliance

Observed attempts to bypass security controls should be investigated according to the organization's incident response, acceptable-use, and disciplinary procedures.

## 5. Review

The policy should be reviewed periodically and updated when endpoint technologies, threats, or organizational requirements change.
